## Max-Former on datasets

## Static (CIFAR-10, CIFAR-100): 
Train Max-Former with the paper’s full configuration: 
Embed-Orig/Embed-Max/ Embed-Max patch embedding, Identity/DWC-3/SSA token mixing, membrane shortcut.

## Neuromorphic (CIFAR10-DVS, DVS128 Gesture):
Train Max-Former using the neuromorphic configuration: 

2 stages, Embed-Max+/Embed-Max patch embedding, DWC-3/SSA token mixing. Test whether high-frequency restoration is even more critical for event-based data.
